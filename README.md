Physimo is a rehab tracking app that helps user to log physiotherapy exercises with photo attachments, which are processed using Google's MediaPipe Postlandmark ML model to estimate joint coordinates. The app computes joint angle metrics with those landmark coordinates, using 2D/3D geometry calculation. 

A dashboard visualise knee mobility range over time, helping users track their rehab progress.
